name: explain-clearly
description: 用更容易理解的语言解释概念、回答问题或重新组织已有回答，按需举例和绘制 Mermaid 图。Use only when the user explicitly invokes $explain-clearly or explicitly asks to use this skill.
---

仅在用户明确调用本 skill 时使用；不要因“解释一下”“没看懂”等普通表达自行启用，也不要由其他 agent 或 skill 自动触发。

目标是让用户真正理解，不只是缩短文字或替换同义词。根据当前问题和对话判断用户已知什么、卡在哪里，从熟悉的内容连接到新概念；信息足够就直接解释，只有缺失信息会实质改变答案时才简短澄清。

默认用简体中文，先直接给出核心答案，再按理解所需的顺序解释“为什么”和“如何发生”。用短句、具体的主语和动词；必要术语首次出现时用白话解释。保留关键条件、因果关系和不确定性，不为通俗而失真，也不臆测用户背景。

抽象内容难以落地时，给一个贴近当前问题的具体例子，走完“情境 → 发生什么 → 为什么得到这个结果”，并对应回概念。使用类比时说明对应关系；容易误导的地方点明类比的边界。

当流程、因果、层级或交互关系用图更容易看懂时，加入简洁的 Mermaid 代码块。节点使用直白标签，箭头含义清楚，图与文字一致；图只保留理解当前问题必需的关系。简单问题无需配图，图不能代替关键解释。

只写解决当前困惑所需的内容，不强制套用标题、例子或图表模板。用户仍不理解时，换切入点、例子或拆解粒度，不重复原话，也不自动变成测验或连续追问。
